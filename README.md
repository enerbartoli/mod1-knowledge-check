# MOD 1 Knowledge Check — moved

This site has been retired. The HERO User Manual and its training resources
now live on the new HERO Enablement site:

https://hero-enablement.apps.ai-dev.tiamat.cloud

GitHub Pages (https://enerbartoli.github.io/mod1-knowledge-check/) now serves
only a "This site has moved" notice (`index.html`) and a matching `404.html`,
so old deep links (e.g. `mod2.html`, `speed1.html`) show the same notice.

continue, so they notice the change and update their bookmarks.

**Access requires the Hasbro network.** The notice reminds visitors to connect
to the Hasbro VPN or the Hasbro office network, and clicking the button opens
a pop-up repeating that reminder before they continue to the new site.

The previous quiz app, question banks, Apps Script source and tooling are
preserved in git history and on the `archive/pre-redirect-2026-10-13` branch.
